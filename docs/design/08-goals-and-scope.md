# Goals, non-goals, anti-goals


**Goals:** a working end-to-end system meeting the standard exit checks; a
clear, defensible framing; an honest comparison against the rule baseline.

**Non-goals:** predicting delivery date (regression), carrier selection,
real-time streaming (Phase 8), using review text, the Marketing Funnel join.

**Anti-goals (failure even if it "works"):**
- a strong metric that comes from leakage (random split, future seller stats,
  review fields);
- simulated business numbers presented as real;
- a model that does not beat the rule baseline being shipped anyway.
